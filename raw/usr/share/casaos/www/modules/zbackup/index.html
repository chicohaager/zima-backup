What kind of job is this?

The kind of an existing job cannot be changed — create a new job instead.

1

What do you want to protect?

The ZimaOS box itself — everything that makes it yours:

  • settings in /etc (network, users, hostname, SSH keys)
  • ZimaOS state: apps, users, app store, file service
  • installed modules
  • app data (/DATA/AppData)

Not the operating system itself: ZimaOS is reinstalled from IceWhale's installer, then this backup puts your box back. Docker images are pulled again from the registry.

2

Where should it go?

The module talks to the drive directly with ZimaOS' own sign-in — not through the slow mounted folder. First backup of a large folder takes long (measured: about 0.35 MB/s to Google Drive); later runs only send changes. Sync runs at full upload speed.

A sync to a cloud drive uploads every file on its own — Google Drive manages about one file per second, large or small. Many small files? A Backup packs them and runs at full speed.
